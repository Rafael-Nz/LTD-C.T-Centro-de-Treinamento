# Documentação do Sistema LTD - C.T

Este diretório contém a documentação técnica e operacional completa do **LTD - C.T - Centro de Treinamento**. Esta estrutura foi projetada para funcionar nativamente como a **Wiki oficial do repositório**.

> 📖 **Página Principal da Wiki:** Acesse **[Home.md](Home.md)** para o índice completo e navegação interativa.

---

## 🗂️ Estrutura de Diretórios

- **[`Home.md`](Home.md)**: Página inicial da Wiki com mapa visual do sistema.
- **[`_Sidebar.md`](_Sidebar.md)**: Menu lateral global para a Wiki do GitHub/GitLab.
- **[`_Footer.md`](_Footer.md)**: Rodapé global da Wiki.
- **[`arquitetura.md`](arquitetura.md)**: Documentação detalhada da arquitetura do sistema e camadas.
- **[`instalacao.md`](instalacao.md)**: Guia de instalação dos pré-requisitos e dependências.
- **[`setup.md`](setup.md)**: Procedimento passo a passo para setup do banco, `.env` e inicialização.
- **[`wiki_guia.md`](wiki_guia.md)**: Instruções para sincronizar estes arquivos com a Wiki do repositório.
- **[`admin/`](admin/README.md)**: Arquitetura, roteamento e telas do Painel Administrativo.
- **[`core/`](core/README.md)**: Componentes base da API (Auth, Database, Http, DTO, Validation, DataTables, Docs).
- **[`modules/`](modules/README.md)**: Documentação de todos os módulos de negócio da API.
- **[`database/`](database/README.md)**: Dicionário de tabelas, relacionamentos e regras de banco.
- **[`tools/`](tools/README.md)**: Documentação dos scripts CLI, automações agendadas e suíte de testes.
- **[`sql/`](sql/)**: Scripts SQL (setup, migrations, testes, permissões e auditoria).
